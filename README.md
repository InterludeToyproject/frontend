# RegRadar Frontend

JB금융그룹 준법심의 AI Agent — Streamlit 프론트엔드

## 기술 스택

- Python 3.11
- Streamlit

## 프로젝트 구조
frontend/

├── app.py                   # 메인 홈 화면

└── pages/

├── 1_심의요청.py         # 콘텐츠 심의 + 수정본 생성

├── 2_규제변경.py         # 규제 공시 크롤링 + 소급 탐지

└── 3_대시보드.py         # 심의 현황 + 보안 모니터링

## 주요 기능

- 콘텐츠 심의 요청 및 결과 확인
- 위반 문구 하이라이팅 (🔴HIGH / 🟠MEDIUM / 🟡LOW)
- 예상 과태료 시뮬레이터
- AI 수정본 자동 생성 + 원본 비교
- 다국어 콘텐츠 심의 (langdetect 50개 언어)
- 환각 방지 조문 검증 결과 표시
- 규제 공시 실시간 크롤링 (금융위·개인정보위·금감원)
- 소급 위반 탐지
- 승인/반려 레포트 다운로드
- 프롬프트 인젝션 탐지 + 보안 모니터링 대시보드

## 설치 및 실행

### 1. 백엔드 서버 먼저 실행

프론트엔드는 백엔드 API에 의존합니다.
백엔드 README를 참고하여 FastAPI 서버를 먼저 실행하세요.

백엔드 서버: http://127.0.0.1:8000

### 2. 가상환경 활성화

```bash
# Mac/Linux
source venv/bin/activate

# Windows
venv\Scripts\activate
```

### 3. 프론트엔드 실행

```bash
cd frontend
streamlit run app.py
```

브라우저 자동으로 열림: http://localhost:8501

## 사용 방법

### 콘텐츠 심의

1. 좌측 메뉴 → 심의요청
2. 콘텐츠 입력 또는 예시 불러오기
3. 콘텐츠 유형 + 작성자 입력
4. 심의 요청 버튼 클릭
5. 결과 확인 (위험도 / 하이라이팅 / 과태료 / 수정본)
6. 승인 또는 반려 처리

### 규제 변경 추적

1. 좌측 메뉴 → 규제변경
2. 실시간 규제 공시 탭 → 지금 바로 수집
3. 소급 위반 탐지 탭 → 검토 기준 입력 후 탐지

### 대시보드

1. 좌측 메뉴 → 대시보드
2. 심의 현황 탭 → 전체 통계 + 이력
3. 보안 모니터링 탭 → 인젝션 탐지 이벤트 확인
